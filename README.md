# AeroSim
This is a fluid dynamics simulator, you input you cad model into and it give you the drag, lift, respective coeff., and roll tendency (the want of the object to roll). 

# Description
The project revoles around the ideas and principles of aerodynamics, the main focus of this topic and why I decided to do this. The main idea is that you shouldn't have to go through the work of doing all the math and wasting you time when you could be building and/or CAD modeling it(unless you like the math like me). So, I went ahead and created it, it give you the main variables, and if you wish to go deeper you can derive and L/D ratio that'll tell you is your object is producing more lift than drag and vice versa. How to use it, simply input a cad model and then let the computer do everything else, you dont gotta worry about anything.

# Getting started
Nothing really, it's hosted on GitHub pages and so It works from the browser, no need to install anything and should work perfectly fine.

Its pretty straight forward, theres a button to import an STL or OBJ, these are the only accepted versions, I don't think STEP files will work I tried it once and came up really weirdly, so I rather you guys convert it to and STL or OBJ then import it in.
